# Source and rights record

Editorial verification performed 2026-09-12. Text is paraphrased; no source-page images/audio were embedded. `source_verified` marks the cited editorial source review, not independent coordinate or Android QA approval.

- Bloop: [NOAA Ocean Service](https://oceanservice.noaa.gov/facts/bloop.html), [NOAA PMEL](https://www.pmel.noaa.gov/acoustics/sounds/bloop.html). Observation versus speculation, icequake interpretation and 16× playback warning.
- Wow: [SETI Institute](https://www.seti.org/research/seti-101/the-wow-signal/), [Ehman technical report](https://www.bigear.org/wow20th.htm), [SETI natural-hypothesis discussion](https://www.seti.org/news/the-wow-signal-a-lingering-mystery-or-a-natural-phenomenon/). Intensity code, roughly 72-second window, no established extraterrestrial identification. New natural explanations remain hypotheses.
- Voynich: [Yale Beinecke MS 408](https://beinecke.library.yale.edu/beinecke/collections/beinecke-cipher-voynich-manuscript). Preserved object, material analysis broadly consistent with the fifteenth century, no agreed decipherment. Material age is not a precise date for writing.
- Build compatibility: [Android AGP 8.13](https://developer.android.com/build/releases/agp-8-13-0-release-notes). API 36, Gradle 8.13, JDK 17. This does not claim the source compiled.
- Evaluated map provider: [OpenFreeMap quick start](https://openfreemap.org/quick_start/), [attribution](https://github.com/hyperknot/openfreemap), [MapLibre offline package](https://maplibre.org/maplibre-native/android/api/-map-libre%20-native%20-android/org.maplibre.android.offline/index.html).

The schematic geometry, launcher vector and UI are original for this prototype. No third-party map tiles, photographs, generated historical representations or audio files are included. Platform/AndroidX dependencies remain subject to their own licenses when downloaded; no third-party binaries were redistributed in this source archive.
